# Negafa Jolie Dame

Site vitrine responsive prêt à publier sur GitHub Pages, Netlify ou tout hébergement statique.

## Fichiers
- `index.html` : structure et contenu
- `styles.css` : design responsive
- `script.js` : menu mobile, galerie, lightbox, témoignages, vCard et formulaire WhatsApp
- `assets/images/` : images optimisées au format WebP à partir de la référence fournie

## Mise en ligne sur GitHub Pages
1. Créez un nouveau repository.
2. Ajoutez tous les fichiers en conservant la structure des dossiers.
3. Ouvrez **Settings → Pages**.
4. Sélectionnez la branche `main` et le dossier `/root`.
